TC-02 Create a Cash Sale (Paid immediately) POS — Core
Setup Ensure at least one product exists (e.g. Turmeric 100g). No buffer stock is needed — stock enforcement is disabled for agents.
  1. Click POS / Billing in the sidebar
  2. In the product search box, type "Turmeric" and click the result to add it to cart
  3. Set quantity to 2
  4. Click Select Customer → search "Restaurant" → select or create: Momo Corner (phone: 9841000001)
  5. Select payment method: Cash
  6. Enter amount received (e.g. 500)
  7. Click Complete Sale
✓ Expected
  • Success notification "Sale completed"
  • Receipt number generated (e.g. RCPT-XXXXX)
  • Cart clears, new session starts
  • If customer phone provided, WhatsApp receipt prompt appears
  • Sale shows payment_status = paid
✗ Should NOT happen
  • "Insufficient Stock" error blocking the sale
  • 500 error during completion
  • Sale saved but payment_status = unpaid
TC-03 Create a Credit / Preorder Sale (Customer pays later) POS — Credit Flow
Scenario Bina visits a sweet shop. They want 5kg cashews but stock isn't in hand yet. Agent takes the order as a credit.
  1. Open POS, add Cashews 1kg × 5 to cart
  2. Select customer: Angan Sweets (phone: 9841000002) — create if not exists
  3. Select payment method: Credit
  4. Click Complete Sale
✓ Expected

  • WhatsApp receipt (if sent) shows amber "ORDER CONFIRMED — Payment due on delivery" banner
